# Support

Use [GitHub Issues](https://github.com/joomtheme/JoomTheme-Gallery/issues) for reproducible bugs and focused feature requests.

Before opening an issue:

1. Update to the latest published package.
2. Confirm the problem with Joomla 6.1.x and PHP 8.3 or later.
3. Search existing issues for the same symptom.
4. Temporarily test with Joomla's core administrator and frontend templates when a template override may be involved.

A useful bug report includes the JoomTheme Gallery, Joomla and PHP versions; browser and database details; exact reproduction steps; expected and actual results; relevant Joomla/PHP log excerpts; and screenshots when the problem is visual.

Do not publish credentials, private URLs, personal data or exploit details. Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).
